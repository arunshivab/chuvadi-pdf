Add JBIG2 decode: generic region, symbol dictionary, text region

Implements arithmetic JBIG2Decode for embedded-organisation streams.

Core (MQ arithmetic coder, segment headers, generic regions):
- MQDecoder/MQEncoder per ITU-T T.88 Annex E (round-trip tested)
- Generic region codec, templates 0-3, adaptive AT pixels, TPGDON
- Segment header parser and page composition (OR/AND/XOR/XNOR/REPLACE)

Symbol dictionary + text region (arithmetic):
- Arithmetic integer coders (IADH/IADW/IAEX/IADT/IAFS/IADS/IAIT) and IAID
- Symbol dictionary decoding via height classes and the generic procedure
- Text region strip/instance placement with reference-corner handling

Registered as the JBIG2Decode stream filter (samples inverted to PDF
polarity). Unsupported paths (Huffman, refinement/aggregate, transposed
text, MMR generic) raise a clear FilterException.

Conformance: decodes the public Norconex sample (symbol dictionary in
the globals stream, text region in the image stream); the decoded bitmap
was visually verified and is locked as a regression fixture.

Tests: MQ coder, generic region, integer coder round-trips, filter
behaviour, and real-file conformance.
